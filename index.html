Lab-to-field calculator for perovskite stability tests

Converts an accelerated laboratory test into the field years it represents at a chosen site, using hourly weather data and the stress-budget model of the review “Are lab stability tests tropical-ready?”

1. Site

Downloads hourly data for 2015–2024 (ten requests, about a minute). If your browser blocks the download, use “Upload file”.

Get it from the NASA POWER Data Access Viewer: community “Renewable Energy”, temporal average “Hourly”, parameters T2M, RH2M, ALLSKY_SFC_SW_DWN and WS10M, format CSV. Ten years are recommended.

Default: rounded latitude, minimum 10°.

A test that ends before the device fails gives a lower bound: the device covers at least this many field years for this stress, not a predicted lifetime. Each test covers one stress; a device is limited by its weakest test. Model details: Section 3 and ESI Section S2 of the review.

Model: Faiman module temperature (open rack U0 = 25, U1 = 6.84; rooftop U0 = 20, U1 = 0), Erbs decomposition and isotropic sky, module-surface humidity at constant vapour pressure, Peck damp-heat model (n = 2.66), (G/1000)0.72·Arrhenius for light and heat, Arrhenius for dark heat, Coffin–Manson exponent 2 for thermal cycling. Weather: NASA POWER (please cite the NASA POWER Project when using these data).

Source code and data: github.com/savisha3/perovskite-tropical-stability. If you use this calculator, please cite: S. Mahalingam, “Are lab stability tests tropical-ready? Mapping heat, humidity and UV stress in the tropics to perovskite solar cell degradation”.
